# levit_assignment
# 우리 가족 맞춤 쇼핑 AI 어시스턴트 (MVP)

35~50세 주부 및 소비자를 타깃으로, 방대한 상품 실제 리뷰 속에서 **사용자별 맞춤 성향(저염, 유기농 등)과 가족 구성원 관점**을 반영해 핵심 내용을 3줄로 요약해 주는 AI 쇼핑 에이전트 서비스입니다.

---

## Tech Stack

* **Frontend**: React (Hooks, Axios)
* **Backend**: Node.js, Express, Cors, Dotenv
* **AI Model**: Google Gemini API (`gemini-3.6-flash`)

---

## Key Features (핵심 기능)

1. **쇼핑 주체(가족 구성원)별 맞춤 뷰**: 
   * 초등학생 자녀를 둔 주부, 부모님 건강을 챙기는 자녀, 1인 가구 자취생 등 페르소나별 관점 반영
2. **상품 선택 및 실시간 리뷰 요약**: 
   * 한우, 고등어, 사과, 방울토마토 등 다양한 상품군 선택 가능
3. **맞춤 성향 태그 및 직접 입력**: 
   * '저염 선호', '국산 재료', '가성비 최고', '유기농 인증' 등의 태그 선택 및 특이사항(예: 알레르기, 당뇨 등) 자유 텍스트 입력 가능
4. **구글 Gemini AI 연동 3줄 리포트**: 
   * (1) 우리 집 맞춤 적합도, (2) 실구매자 리뷰 요약, (3) AI 최종 추천 가이드 제공

## Developer's Note (개발 회고 및 설계 의도)

### 1. 설계 의도 및 핵심 강조 포인트
* **타깃 페인포인트 집중**: 35~50세 주부의 '정보 과부하(Decision Fatigue)'를 해결하기 위해, 방대한 리뷰 속에서 가족 구성원별 맞춤 성향과 특이사항을 즉각 반영하는 AI 에이전트 설계.
* **단 4단계의 직관적 UX**: `[페르소나 선택] ➔ [상품 선택] ➔ [성향/특이사항 입력] ➔ [AI 3줄 리포트 확인]`의 간결한 흐름으로 시연 완성도 극대화.

### 2. 기술적 도전 과제 및 트러블슈팅
* **Google Gemini API 활용**: 무료 APIkey 사용을 위해 ChatGPT 대신  **Google Gemini API (`gemini-3.6-flash`)**를 채택하여, 다량의 리뷰 데이터를 빠르고 효율적으로 처리하며 구조화된 JSON 리포트 생성 구현.
* **개발 환경 정합성 확보**: 초기 수동 설정 과정에서 발생한 리액트 및 백엔드 의존성 충돌 문제를 디렉터리 분리와 패키지 재설치로 신속하게 해결 및 서버 에러 핸들링 구축.

### 3. 아쉬웠던 점 및 개선 여지
* **실제 데이터 연동의 한계**: 보안 및 시간적 제약으로 레브잇(올웨이즈) 실데이터 대신 가상 시뮬레이션 데이터를 활용한 점.
* **UI/UX 디자인 완성도**: 기능 구현(MVP)에 집중하느라 모바일 커머스 특유의 세련된 반응형 디자인 요소를 더 세밀하게 다듬지 못한 점.
* **응답 속도감(인터랙션)**: AI 응답 대기 시간 동안 스켈레톤 UI나 로딩 애니메이션 등 시각적 피드백 디테일이 부족했던 점.
* **확장성**: 향후 실제 커머스 DB와 연동하여 사용자의 구매 이력을 학습하는 **Vector DB 기반 개인화 추천 파이프라인**으로 고도화 가능.
